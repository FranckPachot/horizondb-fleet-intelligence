# HorizonDB Fleet Intelligence Frontend

This React, TypeScript, and Vite application is the operations console for
HorizonDB Fleet Intelligence. It displays shipment lists, PostGIS locations on a Leaflet map,
and grounded answers generated by HorizonDB's built-in AI models.

## Development

The FastAPI backend must be running on `http://127.0.0.1:8000`. From this
directory, install dependencies and start Vite:

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`. Vite proxies `/api` to the local backend. Set
`VITE_API_URL` only when the backend runs at another address.

## Validation

```bash
npm run build
npm run lint
```

See the repository [README](../README.md) for HorizonDB setup, model aliases,
backend commands, and the complete architecture.

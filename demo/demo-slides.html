02 Inside the retrieval tool

Place narrows the field. Meaning finds the answer.

PostGIS and spherical-quantized DiskANN cooperate in one HorizonDB query path.

FI Spatial-semantic candidates

PostGIS filters. SQ DiskANN retrieves.

CREATE TABLE horizon_ship.shipments (
  shipment_number text UNIQUE,
  origin_position geometry(Point, 4326),
  destination_position geometry(Point, 4326),
  current_position geometry(Point, 4326),
  embedding vector(1536)
);

WHERE ST_DWithin(
  current_position::geography,
  :center, :radius_meters
)
ORDER BY embedding <=> :query_vector
LIMIT 100;
1
Map-selected radiusSRID 4326 points and ST_DWithin keep candidates inside the operator's search area.
2
Approximate nearest neighborsDiskANN retrieves semantic candidates while transaction-local GUCs support filtered search.
3
Hybrid evidenceA 72/28 semantic-spatial score exposes meaning, distance, and final rank.
PostGISOne row combines business, spatial, and vector data
